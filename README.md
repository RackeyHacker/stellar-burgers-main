# Stellar Burgers

Проект космической бургерной с возможностью конструирования и заказа бургеров.

## Описание проекта

Stellar Burgers - это веб-приложение для создания и заказа космических бургеров. Пользователи могут:
- Конструировать бургеры из различных ингредиентов
- Оформлять заказы
- Отслеживать статус заказов в реальном времени
- Просматривать историю своих заказов
- Управлять своим профилем

## Технологический стек

### Frontend
- **React** - библиотека для разработки пользовательского интерфейса
- **Redux Toolkit** - управление состоянием приложения
- **TypeScript** - строгая типизация для повышения надежности кода
- **React Router v6** - маршрутизация и навигация
- **React DnD** - реализация drag-and-drop функционала

### Безопасность и авторизация
- Полная система авторизации (регистрация, вход, восстановление пароля)
- JWT токены с хранением в cookies
- Защищенные маршруты
- Обновление токенов

### Тестирование
- **Jest** - модульное тестирование
  - Тесты редьюсеров
  - Тесты асинхронных операций
  - Тесты начального состояния
- **Cypress** - e2e тестирование
  - Тесты функционала конструктора
  - Тесты модальных окон
  - Тесты процесса заказа

## Установка и запуск

### Требования
- Node.js >= 14.x
- npm >= 6.x

### Установка
```bash
# Клонирование репозитория
git clone <URL репозитория>

# Установка зависимостей
npm install
```

### Запуск

```bash
# Режим разработки
npm start

# Сборка проекта
npm run build

# Запуск тестов
npm test

# Запуск Cypress тестов
npm run cypress:open
```
