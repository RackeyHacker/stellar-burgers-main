# Stellar Burgers

Проект космической бургерной - веб-приложение для создания и заказа бургеров.

[Макет](<https://www.figma.com/file/vIywAvqfkOIRWGOkfOnReY/React-Fullstack_-Проектные-задачи-(3-месяца)_external_link?type=design&node-id=0-1&mode=design>)

[Чеклист](https://www.notion.so/praktikum/0527c10b723d4873aa75686bad54b32e?pvs=4)

## Используемые технологии
- **Create React App** — для быстрого и удобного старта разработки проекта
- **Redux Toolkit** — эффективное управление состоянием приложения
- **React Router с полной системой авторизации** — регистрация, восстановление и сброс пароля, профиль пользователя
- **Хранение токенов в cookie** — надёжный и удобный способ авторизации
- **Защищённые маршруты** — ограничение доступа к страницам без авторизации
- **TypeScript** — строгая типизация компонентов и утилит для повышения надёжности
- **Jest тесты** — тестирование бизнес-логики и всех редьюсеров
- **Cypress тесты** — e2e тестирование основного функционала
- **React DnD** — реализация drag-and-drop для конструктора

## Основной функционал
- Конструктор бургеров с drag-and-drop
- Лента заказов в реальном времени
- Личный кабинет с историей заказов
- Полная система авторизации

## Установка и запуск проекта
```bash
# Установка зависимостей
npm i

# Запуск проекта
npm start

# Запуск тестов
npm test

# Запуск Cypress тестов
npm run cypress
```
